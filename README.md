# 🥭 Mango Context Kit

**A lightweight, local-first tool for organizing project context and generating clean handoff briefs.**

Mango Context Kit helps you keep the important details of a project in one place, so you can pick up where you left off or hand work over without losing context.

## ✨ Features

- 📝 **Project Organization** — Keep goals, context, decisions, constraints, completed work, open questions, and next steps together.
- 📋 **Markdown Handoff Briefs** — Generate structured briefs that are easy to read and share.
- 🎨 **Tone Selection** — Choose a casual Gen Z tone or a professional Millennial tone.
- 📎 **Copy & Download** — Copy your brief or download it as a file.
- 💾 **Local Storage** — Keep project data in your browser.
- 🔄 **Backup & Restore** — Export and restore project data using JSON files.
- 🥭 **Mango Loading Animation** — Enjoy a playful loading animation while your brief is prepared.

## 🚀 Getting Started

### Run Locally

1. Clone or download this repository.
2. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
3. Open `index.html` in your browser.

No backend or AI API is required.
